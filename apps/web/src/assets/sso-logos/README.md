# Sign-in logos

`google-g.svg` is the multicolour "G" shown on the Google Workspace single sign-on card in
Setup. It is drawn as an image, in its own colours, because the sign-in guidelines ask for the
mark unaltered.

## Source

- Downloaded from Google's hosted sign-in assets:
  `https://www.gstatic.com/firebasejs/ui/2.0.0/images/auth/google.svg`
- Fetched on 2026-10-08. The editor metadata, ids, group transforms and the empty bounding
  path were removed; the four coloured paths and the copyright line are unchanged.
