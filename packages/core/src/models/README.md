# Kernel models

Drizzle schema for the kernel's tables. Models are schema only: no queries, no
behaviour. Services import them; nothing here imports a service.

## Conventions

- Tables are snake_case and plural (`settings`, `module_grants`); columns are
  snake_case. The TypeScript property is the camelCase of the column.
- Primary keys are UUIDv7 generated by Postgres 18: use `primaryId()` from
  `conventions.ts`, which declares `id uuid primary key default uuidv7()`.
  Exceptions are tables whose natural key is already a stable identifier the
  rest of the system uses (`modules.id` is the module id, `schema_changelog`
  is keyed by `(module, id)` like Liquibase's own table).
- Every table has `created_at` and `updated_at`: spread `...timestamps()`.
  Use `timestamptz(name)` for every other timestamp.
- Indexes are declared in the table's third argument and ship in the same
  changeset as the table.
- Soft delete (`deleted_at`) only on issues, pages and comments.

## Adding a table (other streams)

1. Add one file here, e.g. `models/users.ts`, exporting the `pgTable` and its
   `$inferSelect` row type.
2. Add one line to `index.ts`: `export * from './users.ts';` (keep the list
   alphabetical so parallel branches merge cleanly).
3. Write the changeset in `packages/core/changelog/` with the next numeric
   prefix (see `services/changelog/README.md`). The changeset's SQL is the
   source of truth for the database; the model must describe the same shape.

Module tables live in the module's own `server/src/models/` and its own
`changelog/` folder, never here.
