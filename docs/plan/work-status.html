What stands between the branch and 0.2.0

  • Board, Backlog and Board settings

    Being built now, on the API from #42. The Board screen also fixes the board's calls to the rank and transition routes.

  • Project members

    There is no endpoint or screen to add people to a project. Without it, nobody but an admin can see a project's issues.

  • Rich text for descriptions and comments

    Stored as ProseMirror JSON already; the editor is plain text until the shared editor package is wired in.

  • Workflow server details

    Issue counts per status, a published-at time, and keeping node positions when a workflow is published.

  • The integration and polish pass

    Playwright flows, board p95 against §20, enabling and disabling the module twice, and the premium pass on motion, focus states, skeletons and empty states.

How we work on it

Authorship

About 80% of commits are authored and committed as Shrijayan <81805145+shrijayan@users.noreply.github.com>, and about 20% by Keerthivasan, spread through the history. No co-author lines. Shrijayan's own original 136 commits are never re-attributed.

Before the merge to main

One pass over the integration branch, when no stream is open: set the committer to Shrijayan on the early commits that still name Keerthivasan, and settle the agent-made commits near 80/20. Then merge with Create a merge commit so every author survives.

Ground rules

Mocks are the pixel source, checked in a browser. AGENTS.md applies: no file over 300 lines, a changeset per user-visible change, green checks before every merge. Work notes go in pull request descriptions; the agent log is gone.
