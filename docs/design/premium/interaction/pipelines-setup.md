# Pipelines: Set up and Settings

## Set up Pipelines (`/pipelines/start`)

**Primary job.** Take an empty install to its first Prod deploy. One checklist read from what
exists: GitHub connected (Bemmoly's Settings › Code hosts), the applications the scan found
accepted, runners or your own CI, a cloud, a first deploy. The first step not done is raised
with its action. The scan's proposals are listed with their signals and CODEOWNERS owner;
"Add N applications" accepts them with a group for those without one and opens the
application.yaml pull requests. Reachable from Settings; a catalog with no applications should
lead here (Scan GitHub).

## Settings (`/pipelines/settings`, `G S`)

Light or dark on this device (T anywhere); the theme and typeface are the workspace's (applied
from `/me`, ADR 0021) with a way to Bemmoly's settings; Show every key (?); notifications are
Bemmoly's; setup progress; the account.
