# Bemmoly launch film: storyboard

1920 × 1080, 60 fps, about 112 seconds. No voice-over: kinetic type carries the story, cut to a
120 BPM grid (one beat = 30 frames) so a score can be laid under it.

Every product surface is drawn as vector UI in the design system (IBM Plex Sans, the logo's three
blues, lilac for AI only). Nothing is a screen recording.

## Honesty rules (from the launch rules)

- Shipping today: Work, Docs, optional AI, imports (Jira, Confluence, CSV), SSO (OIDC, SAML,
  SCIM), MCP server, themes, automation, webhooks, roadmap forecasts, GitHub and GitLab links,
  one-command install, automatic HTTPS, verified backups, signed updates with rollback, no
  telemetry.
- Roadmap, always labelled "Coming soon", never a date or version: Pipelines (in progress) and the
  nine suite products (People, Time, Expenses, Assets, Licences, Hiring, Access, Performance,
  Helpdesk).
- Competitor names appear only as import sources ("Import from Jira").

| 5  | 42–54 s   | Docs           | One continuous window. A page writes itself with two live cursors; an issue link shows its live status. |
| 6  | 54–63 s   | AI             | Lilac arrives. A question, an answer that streams with its sources. "Off until you turn it on. Your model." |
| 7  | 63–72 s   | The platform   | The whole UI morphs through the themes, light to dark. Feature cards flip in on the beat: imports, SSO, MCP, webhooks, code links. |
| 8  | 72–80 s   | Your server    | A terminal types the one-liner. Ops promises tick in. "One Docker image. One Postgres. Your server." |
| 9  | 80–100 s  | The roadmap    | Pull back to the kernel. Pipelines (in progress) and nine products assemble around it. A light pulse follows one new hire through every product. "Use one. Or all of them." |
| 10 | 100–112 s | Close          | "Everything your company runs on." $0 · unlimited seats · MIT. The lockup, bemmoly.com, the GitHub repo. |
